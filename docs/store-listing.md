## Name

CommandUI

## Short description

A shell that explains each result, and lets you ask for a command in plain words.

## Description

CommandUI is a Windows desktop app with a real shell.

Type a command, or describe what you want. A description becomes a draft. You read the command, in plain words, and choose Run Plan. Nothing drafted runs until you do.

Each command from the command box ends with one sentence: whether it worked, and what to do if it did not.

Text size runs from 100% to 200%. You can make a workflow, edit it, run it, and undo a delete.

Ask uses a model on this computer. If that model is not ready, CommandUI says so and does not invent a command.
