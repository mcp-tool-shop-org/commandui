Every plan says the risk in a sentence.

## What you see

- Low risk. Easy to undo. Run Plan is enough.
- Medium risk. Read the command before you run it. Run Plan is enough. There is no medium-risk checkbox.
- Deletes files: cannot be undone. Or: Runs with higher permissions. Or: High risk. This can be hard to undo.

A high-risk plan stays blocked until you type the folder name. The label is "Type {folder} to run this". When the folder has no usable name, the word is confirm.

Other sentences you may see:

- Can make a change that is hard to undo
- Uses the network

## The rule

Ask never runs a command you have not seen. Run Plan is the approval. Reject runs nothing.
